# Empezar con un Word

Usa esta ruta cuando quieres crear un proyecto documental y escuchar su fuente sin tocar pantallas técnicas.

## Configuración inicial

1. Crea un proyecto desde **Nuevo proyecto**.
2. Elige tu Word u otra fuente documental cuando el proyecto lo solicite.
3. Guarda el proyecto cuando la app lo pida. Esa carpeta guardará audio, visuales, imágenes y decisiones.
4. En Documento, selecciona una oración o usa **Escuchar documento**.
5. Para escuchar rápido, usa **Voz local simple** o **Modo de prueba**.
6. Para video, asigna visuales a los fragmentos desde el panel Visual.

## Qué debes saber

DocuPodcast no abre fuentes como archivos sueltos. El Word no se modifica y las voces, imágenes, el audio y los ajustes viven dentro del proyecto.
