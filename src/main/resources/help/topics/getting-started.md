# Empezar con un Word

Usa esta ruta cuando solo quieres abrir un documento y escucharlo sin tocar pantallas técnicas.

## Configuración inicial

1. Abre tu Word o fuente documental desde **Abrir fuente**.
2. Guarda el proyecto cuando la app lo pida. Esa carpeta guardará audio, visuales, imágenes y decisiones.
3. En Documento, selecciona una oración o usa **Escuchar documento**.
4. Para escuchar rápido, usa **Voz local simple** o **Modo de prueba**.
5. Para video, asigna visuales a los fragmentos desde el panel Visual.

## Qué debes saber

El Word no se modifica. DocuPodcast guarda voces, imágenes, audio y ajustes dentro del proyecto.
