# Escuchar el documento

La playbar permite escuchar desde el inicio o desde el fragmento seleccionado.

## Acciones

- Reproducir desde aquí.
- Pausar o reanudar.
- Detener.
- Cambiar velocidad.
- Generar audio pendiente cuando haga falta.

Si un fragmento aún no tiene WAV, la app puede preparar audio en segundo plano y avisar cuando necesite esperar.
