# Solución de problemas

Usa esta sección cuando una acción no se puede completar.

## Casos comunes

- **No aparece Voz IA avanzada:** el modelo no pasó la prueba WAV o falta configuración.
- **Seleccioné GPU pero usa CPU:** CUDA no está confirmada en el Python local.
- **No puedo exportar MP4:** faltan audio, imágenes, proyecto guardado o prepara Video local desde Configuración.
- **Proyecto con advertencias:** faltan assets, WAVs o referencias. Revisa Integridad del proyecto.
- **No puedo grabar una voz:** revisa permisos de micrófono y vuelve a intentar desde Voces.
- **Una acción falló:** corrige la causa indicada y vuelve a reintentar desde el mismo botón.
