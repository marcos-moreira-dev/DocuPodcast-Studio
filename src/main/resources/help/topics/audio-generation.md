# Audio

El audio se genera por fragmentos para que puedas escuchar, pausar, cancelar y reanudar sin perder lo completado.

## Orígenes disponibles

- **Voz local simple:** ruta rápida si está preparada.
- **Voz IA avanzada:** aparece cuando el modelo y la prueba WAV funcionan.
- **Modo de prueba:** útil para validar el flujo.
- **Audio del computador:** usa un archivo local para el fragmento seleccionado.

Si seleccionas GPU pero CUDA no está confirmada en el Python local, la app avisará antes de usar CPU.
