# Visuales y secuencia visual

El video se construye con imágenes que tú asocias a fragmentos del Documento.

## Acciones

- Selecciona una oración.
- Abre el panel Visual.
- Importa o asigna una imagen.
- Revisa el rail derecho para ver la secuencia visual.
- Exporta MP4 cuando el readiness indique que hay audio e imágenes suficientes.

## Bloques visuales del documento

Un bloque visual detectado desde Word, Markdown o una tabla se muestra en la hoja para que lo revises. No entra al video automáticamente: solo entra si lo asocias como visual del fragmento.

Duración silenciosa por defecto: 5 segundos.

## Regla de render

Fragmentos sin imagen asociada se omiten del video. Imágenes embebidas en Word se muestran como fuente, pero no se convierten automáticamente en video.
