# Voces y tonos

Voces administra muestras de referencia para que Documento pueda generar audio con una voz disponible.

## Flujo recomendado

1. Abre **Voces**.
2. Crea una voz en la biblioteca.
3. Graba o importa la muestra **Neutral**.
4. Agrega otros tonos solo si tienes muestras reales.
5. Vuelve a Documento y elige esa voz para un fragmento.

## Regla importante

Documento solo muestra tonos registrados para la voz seleccionada. Si una voz no tiene muestra Neutral, no debería usarse para generar audio avanzado.
