# Trabajar en Documento

Documento es el lugar principal de trabajo. Aquí lees, seleccionas fragmentos y decides qué tendrá voz, audio o imagen.

## Acciones comunes

- Seleccionar una oración.
- Reproducir desde aquí.
- Asignar voz generada.
- Asignar audio del computador.
- Asignar imagen para video.
- Revisar el índice si el documento tiene estructura.

## Si algo no aparece

La app solo muestra opciones que tienen uso real para el documento abierto. Algunas capacidades dependen del tipo de fuente y de los motores preparados.
