# Prompt para preparar un documento de lectura

Usa este prompt fuera de DocuPodcast para mejorar claridad, títulos y estructura de un documento de estudio antes de abrirlo como fuente documental.

No conviertas el texto en libreto. No inventes narradores, personajes ni escenas. Conserva el contenido como documento.

## Prompt

Revisa el siguiente documento y mejora su claridad para lectura asistida. Mantén estructura documental con títulos, subtítulos, listas y párrafos. No agregues información no presente. No transformes el texto en diálogo ni en libreto.
