# Checklist para documento de lectura

Antes de abrir una fuente en DocuPodcast, revisa:

- El archivo es Word/DOCX, PDF con texto nativo, Markdown o TXT.
- Los títulos y subtítulos son claros.
- Los párrafos no son excesivamente largos.
- Las tablas o imágenes se entienden como apoyo visual.
- El texto está listo para ser leído como documento, no como libreto ni conversación ficticia.
