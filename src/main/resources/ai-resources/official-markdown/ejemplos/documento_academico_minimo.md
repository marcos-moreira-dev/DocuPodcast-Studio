# Documento académico mínimo

Este es un ejemplo de Markdown que DocuPodcast debe abrir como documento fuente normal.

## Tema

La lectura asistida ayuda a estudiar porque combina seguimiento visual, audio y pausas controladas.

## Ideas clave

- El documento fuente se conserva como referencia de lectura.
- La aplicación prepara fragmentos internos para reproducir audio.
- El usuario no necesita importar formatos especiales.

## Cierre

Este archivo no declara contrato especial. Al asociarlo a un proyecto DocuPodcast, entra por el flujo normal de fuente documental.
