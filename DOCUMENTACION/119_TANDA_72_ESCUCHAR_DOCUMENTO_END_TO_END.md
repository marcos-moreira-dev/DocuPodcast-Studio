# Tanda 72 — Escuchar documento end-to-end

T72 agrega el plan ejecutable de aplicación para la acción principal **Escuchar documento**. El cerebro decide si debe abrir fuente, crear narración interna, reutilizar audio, esperar buffer, pedir guardado o generar audio por segmentos.

La fuente sigue siendo solo lectura y el documento narrable conserva la raíz conceptual del producto.
