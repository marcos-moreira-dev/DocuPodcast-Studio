# Tanda 50B — Scrollbars, tabs y build verde visual

Registro documental ampliado de la corrección visual posterior a Tanda 50.

Se modulariza `document-reader.css`, se agregan estilos compartidos para `ScrollBar`, `TabPane`, `ContextMenu` y `MenuItem`, y se corrige el contraste del menú superior para evitar texto blanco sobre fondo claro en menús emergentes.

La tanda mantiene el objetivo del producto: lector narrado de Word/DOCX para usuario no técnico, con configuración técnica separada.
