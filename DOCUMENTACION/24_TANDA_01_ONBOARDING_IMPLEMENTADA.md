# 24 — Tanda 1 implementada: Onboarding

La primera tanda deja un repositorio inicial con:

```text
README.md
AI_HANDOFF.md
VALIDATION.md
pom.xml
src/main/java
src/main/resources/css
src/test/java
scripts
DOCUMENTACION
```

## Qué existe

- App JavaFX mínima.
- Bootstrap simple.
- `ApplicationRuntime`.
- Shell inicial.
- Toolbar con “Abrir Word/DOCX”.
- Pantalla de bienvenida.
- Placeholders de workspaces.
- Tema claro inicial.
- Tests mínimos de documentación.
- Maven Toolchain configurado para JDK 21.
- Guía de `toolchains.xml` para Eclipse Temurin.

## Qué no existe aún

- Importador DOCX real.
- Persistencia `.docupodcast.json`.
- Audio jobs reales.
- Storyboard real.
- SideDock modular real.
- Toolbar contextual por contributors.

## Objetivo de esta tanda

Que otro chat o desarrollador pueda abrir el proyecto y entender el rumbo sin releer toda la conversación.
