# Tanda 35B — Documento como operación principal

La pantalla Documento pasa a ser la superficie principal de lectura/escucha. La acción visible dominante es `Escuchar documento`; internamente puede crear guion, preparar audio o reproducir si ya existe manifest. Las vistas Guion, Audio, Voces y Storyboard siguen disponibles como herramientas avanzadas.
