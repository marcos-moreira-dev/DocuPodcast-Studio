# Tanda 43 — Configuración guiada de motores

La configuración incorpora un módulo de motores guiados para TTS/STT. La ruta prioritaria de voz es XTTS/Coqui; Piper queda como alternativa local liviana; Whisper local queda como ruta STT. No se exponen comandos crudos al usuario normal y no se depende de una URL fija como única fuente de modelos.
