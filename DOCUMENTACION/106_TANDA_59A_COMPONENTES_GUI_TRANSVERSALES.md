# 106 — Tanda 59A: Componentes GUI transversales

T59A aplica el principio de componentes compartidos: botones y filas de acciones repetibles ya no se construyen manualmente en los workspaces principales.

Componentes agregados:

- `ActionButtonFactory`
- `ActionBar`
- `TransportControls`
- `RailActionRow`
- `MetricBadge`
- `InfoBadge`
- `DiagnosticCard`

Workspaces/paneles migrados:

- Guion
- Audio
- Storyboard
- Voces
- Perfil de lectura
- Rail de capas
- Acciones de bloque
- Estructura documental
- SideDock

La tanda mantiene el comportamiento existente y prepara la limpieza visual posterior.
