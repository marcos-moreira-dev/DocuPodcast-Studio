# 34 — Roadmap de MVP a producto

## MVP útil

```text
DOCX → Guion → WAV por segmentos → progreso → export WAV
```

Debe resolver el dolor principal: estudiar notas Word escuchándolas.

## Versión 0.2

- Reanudación fuerte.
- MP3 si hay FFmpeg.
- Voice library básica.
- Personajes.

## Versión 0.3

- Storyboard con imagen por segmento.
- Playback sincronizado.
- Export package.

## Versión 0.4

- Recursos IA.
- Markdown importable/exportable.
- Guía integrada completa.

## Versión 0.5

- Estilos emocionales según capacidades del motor.
- Rango interno de texto.
- Exportación PDF del guion.

## Futuro

- Video simple de storyboard.
- Alineación más fina.
- Mejoras de voz.
- Transcripción inversa con Whisper.
