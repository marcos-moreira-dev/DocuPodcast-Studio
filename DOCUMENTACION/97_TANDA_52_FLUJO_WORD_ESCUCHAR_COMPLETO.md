# Tanda 52 — Flujo Word → escuchar completo

La Tanda 52 agrega una tarjeta de estado de flujo dentro del workspace Documento para que el usuario vea claramente qué falta para escuchar el documento: abrir Word, preparar guion, guardar proyecto, generar audio por chunks o reproducir. La lógica técnica queda detrás; Documento sigue siendo la pantalla operativa principal.
