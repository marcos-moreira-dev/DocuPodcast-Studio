# Tanda 81G — Retiro/degradación de vistas secundarias redundantes

T81G formaliza que Inicio y Documento son las únicas superficies principales. Guion, Audio, Voces y Storyboard completo quedan como herramientas avanzadas, accesibles desde el menú Herramientas y marcadas como `(avanzado)`. También corrige el source test de T81F para aceptar el nuevo componente transversal `ToolbarActionButton`.
