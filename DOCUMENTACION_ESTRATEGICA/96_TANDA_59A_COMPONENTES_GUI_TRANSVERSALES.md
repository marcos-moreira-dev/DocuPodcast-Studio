# Estrategia — Tanda 59A: contrato de componentes GUI

DocuPodcast necesita parecer simple aunque internamente sea complejo. Para lograrlo, las pantallas no pueden inventar controles propios. T59A consolida un catálogo de acciones y componentes de soporte que será la base para el rediseño del Documento, el refactor del Shell/ViewModel y el smoke real.

La regla estratégica queda fija:

```text
Primero contrato visual transversal, luego limpieza UX, luego refactor interno.
```
