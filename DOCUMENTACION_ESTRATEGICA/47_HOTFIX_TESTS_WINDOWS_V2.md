# Estrategia — Hotfix tests Windows v2

Este hotfix es de estabilización previa a Tanda 15. No agrega capacidades nuevas de producto. Corrige incoherencias entre UI actual, tests fuente y comportamiento específico de Windows.

Reglas confirmadas:

- Los tests deben ser multiplataforma en rutas.
- La UI debe usar lenguaje de producto, no jerga de implementación.
- Los source tests deben seguir la UI real y no etiquetas históricas.
- Antes de release candidate, la suite local debe quedar verde.
