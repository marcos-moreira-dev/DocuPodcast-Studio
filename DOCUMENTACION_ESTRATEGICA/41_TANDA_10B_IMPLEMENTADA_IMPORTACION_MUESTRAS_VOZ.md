# Tanda 10B implementada — Importación de muestras de voz

## Resultado

DocuPodcast Studio ahora puede importar una muestra de voz seleccionada por el usuario y registrarla como asset relativo del proyecto.

## Valor estratégico

Esta tanda prepara tres capacidades futuras:

1. usar voz propia como referencia;
2. usar voces autorizadas con consentimiento;
3. preparar audio fuente para workflows de voz humana, TTS avanzado o STT/Whisper.

## No se incluyen audios estáticos

Los archivos de audio reales del usuario no se copian al repositorio. La app permitirá seleccionarlos localmente. Esto evita subir muestras personales dentro del código fuente.
