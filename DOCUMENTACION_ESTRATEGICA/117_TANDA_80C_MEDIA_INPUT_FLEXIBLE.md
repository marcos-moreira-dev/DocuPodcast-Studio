# Estrategia — T80C

La app debe evitar cabina de avión: no hay botones separados para efecto, voz humana o ambiente. El cerebro acepta media flexible y la interfaz futura debe mantener una sola acción clara: `Asignar audio`.

La configuración conserva la complejidad técnica: FFmpeg, rutas, CPU/GPU, comandos, diagnóstico.
