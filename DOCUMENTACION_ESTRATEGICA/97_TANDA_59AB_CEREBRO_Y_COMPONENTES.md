# Estrategia — Tanda 59A-B: componentes y cerebro

La siguiente fase se divide en dos frentes:

1. Catálogo de componentes transversales: lenguaje, criterios y roles visuales para el front-end.
2. Auditoría/refactor del cerebro: estructura funcional equivalente al backend en una app desktop JavaFX.

La interfaz final todavía puede cambiar. El cerebro debe quedar ordenado para que el rediseño no dependa de una clase central gigantesca ni de acciones dispersas.
