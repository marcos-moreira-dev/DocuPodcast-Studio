# Estrategia — Tanda 81B Documento limpio

T81B refuerza la separación estratégica entre experiencia y diagnóstico.

## Experiencia

El usuario abre un documento, lee, escucha y selecciona fragmentos. No necesita ver metadatos técnicos ni entrar a configuración desde la portada.

## Diagnóstico

Los datos técnicos existen para usuarios avanzados y para soporte, pero viven en paneles específicos.

## Decisiones

- Configuración solo desde menú superior.
- Bienvenida como superficie comercial/operativa.
- Hoja central sin dump de metadatos.
- Metadatos conservados en Detalles.

## Próximo paso

T81C debe introducir la barra flotante de lectura global, manteniendo el mismo criterio: controles concretos, no cabina técnica.
