# Tanda 2.5 implementada — UI de proyecto y DOCX

Esta tanda cumple el puente entre persistencia y uso real: la aplicación deja de ser solo scaffolding y empieza a permitir crear, abrir, guardar y alimentar un proyecto desde Word.

La decisión Word-first queda reforzada: Markdown sigue siendo puente IA/humano, pero el botón destacado de la toolbar es `Abrir Word/DOCX`.
