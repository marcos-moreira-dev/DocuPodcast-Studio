# Tanda 11 — Storyboard básico

## Objetivo

Asociar imágenes a segmentos y mostrarlas visualmente.

## Dominio

- `MediaAsset`;
- `StoryboardDocument`;
- `StoryboardScene`;
- `StoryboardBinding`;
- `StoryboardLayout`.

## UI

- Storyboard workspace visual/canvas;
- Media Library panel;
- scenes panel;
- image properties;
- preview.

## MVP

- una imagen por segmento;
- importar imagen;
- asociar a segmento;
- seleccionar escena;
- resaltar escena activa.

## Criterios

- Imagen se copia a `media/images`.
- Asset usa ruta relativa.
- Binding apunta a segmento existente.
