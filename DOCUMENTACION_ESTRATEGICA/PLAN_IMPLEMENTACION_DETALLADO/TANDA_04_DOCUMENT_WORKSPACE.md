# Tanda 4 — Document Workspace

## Objetivo

Mostrar el documento importado con scroll y SideDock.

## Presentation

- `DocumentWorkspaceView`;
- `DocumentReaderView`;
- `DocumentStructurePanel`;
- `DocumentPropertiesPanel`;
- `DocumentDiagnosticsPanel`.

## UI

Centro:

- documento con bloques;
- títulos/subtítulos diferenciados;
- párrafos legibles;
- aviso de imagen;
- aviso de tabla;
- selección de bloque.

SideDock:

- estructura;
- propiedades;
- diagnóstico;
- ayuda.

## Criterios

- Abrir DOCX desde toolbar.
- Ver bloques con scroll.
- Seleccionar bloque y ver propiedades.
- Diagnóstico muestra número de bloques, imágenes, tablas y advertencias.
