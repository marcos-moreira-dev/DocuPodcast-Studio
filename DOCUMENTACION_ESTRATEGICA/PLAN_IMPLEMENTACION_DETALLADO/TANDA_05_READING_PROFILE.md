# Tanda 5 — Reading Profile

## Objetivo

Configurar reglas para detectar títulos, subtítulos e imágenes.

## Dominio

- `ReadingProfile`;
- `HeadingDetectionRules`;
- `ImageNarrationPolicy`;
- `TableNarrationPolicy`.

## UI

- diálogo de perfil de lectura;
- preview de clasificación;
- marcar bloque como título/subtítulo/párrafo/ignorar.

## Reglas

- estilo Word;
- tamaño de fuente;
- negrita;
- texto corto;
- numeración;
- fallback manual.

## Criterios

- Cambiar perfil actualiza clasificación.
- Se conserva configuración en proyecto.
- No modifica DOCX original.
