# Tanda 15 — Packaging y release

## Objetivo

Preparar app distribuible.

## Entregables

- jpackage app-image;
- MSI futuro;
- iconos;
- scripts de release;
- validación local completa;
- licencia y README final;
- diagnóstico de motor.

## Criterios

- App abre en máquina limpia con Java runtime incluido o documentado.
- Toolchain Java 21 Temurin validado.
- Tests pasan.
- No se incluyen modelos gigantes en paquetes por error.
- Release checklist completado.
