# Estrategia — Tanda 81E

El rail derecho deja de competir con el inspector izquierdo. La estrategia de producto queda:

```text
izquierda = operar fragmento
centro = leer y escuchar
derecha = ver medios y navegar
```

Esto reduce saturación cognitiva y evita que DocuPodcast parezca una cabina técnica. La navegación por medios queda preparada para storyboard simple, imágenes asignadas y assets visuales sin convertir el workspace en editor de video.
