# Estrategia — Tanda 81D: inspector contextual

La Tanda 81D reduce la sensación de cabina técnica al mover la operación por fragmento al sidebar izquierdo. Esta decisión acerca DocuPodcast a un modelo de lector narrado con inspector, similar en abstracción a herramientas como Blender: área central limpia, panel contextual compacto, y detalles técnicos bajo demanda.

## Impacto estratégico

- Documento se consolida como workspace principal.
- El usuario ya no necesita navegar a vistas de voz/audio/storyboard para tareas básicas.
- El rail derecho queda disponible para miniaturas y navegación visual.
- Se prepara el camino para T81E, T81F y T81G.

## Riesgos controlados

- No se toca el contrato del cerebro V1.
- No se eliminan capacidades avanzadas.
- No se agregan controles JavaFX hardcodeados.
- No se vuelve a mostrar metadata técnica en la hoja central.
