# FFmpeg local

Coloca aquí los binarios locales de FFmpeg:

```text
tools/ffmpeg/bin/ffmpeg.exe
tools/ffmpeg/bin/ffprobe.exe
```

`ffprobe.exe` es opcional para diagnóstico avanzado; `ffmpeg.exe` es necesario para preparar audio/video.
DocuPodcast no usa FFmpeg desde PATH ni instalaciones globales.
