# Tanda MOTOR-PERF1 / MOTOR-GPU1 — CPU/GPU honesto

Esta tanda introduce una lectura honesta del hardware disponible: una GPU detectada solo habilita una candidatura, pero no se declara aceleración real hasta que exista una prueba del motor o del componente de video.

La tanda también corrige el guardarraíl HF4 que esperaba el texto exacto “Falta preparar el entorno local de ejecución”.
