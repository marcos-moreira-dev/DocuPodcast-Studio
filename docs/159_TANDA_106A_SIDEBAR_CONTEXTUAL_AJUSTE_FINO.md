# Tanda 106A implementada — Sidebar contextual ajuste fino

T106A es una tanda correctiva y de pulido sobre T106.

## Resultado

El sidebar izquierdo queda mas coherente con la operacion real del usuario:

1. `Texto` / `Fragmento` revisa la seleccion y permite reproducir desde ahi.
2. `Audio` configura voz IA, estilo o audio local.
3. `Imagen` elige o quita imagen y muestra una vista previa local.

Los scrolls de los sidebars ocupan toda la altura disponible para evitar paneles cortados con espacios vacios.
