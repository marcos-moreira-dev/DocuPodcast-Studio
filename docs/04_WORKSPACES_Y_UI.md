# Workspaces y UI

## Welcome

Pantalla inicial clara, inspirada en DMS, con acciones principales:

- Nuevo proyecto.
- Abrir Word/DOCX.
- Abrir proyecto.
- Importar guion Markdown.
- Biblioteca de voces.
- Guía.

## Document Reader

Workspace estructurado para importar y revisar documentos.

SideDock:

- Estructura.
- Propiedades.
- Diagnóstico.
- Ayuda.

## Script Editor

Workspace estructurado para guion narrable.

SideDock:

- Segmentos.
- Propiedades.
- Personajes y voces.
- Estilos.
- Storyboard bindings.
- Validación.
- Ayuda.

## Storyboard

Workspace visual/canvas para escenas e imágenes asociadas.

MVP: una imagen por segmento.

## Audio Jobs

Workspace estructurado para generación por segmentos.

Debe mostrar progreso, ETA, fallidos, reintentos y logs.

## Voice Library

Voces prediseñadas, voz propia y voces autorizadas.

## Observability

Logs, diagnóstico, estado del motor, jobs recientes y copiar diagnóstico.
