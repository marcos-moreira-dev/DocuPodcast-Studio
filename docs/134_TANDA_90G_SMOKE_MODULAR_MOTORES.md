# Tanda 90G — Smoke real modular de motores

Tanda basada en T90F.

Permite ejecutar smoke real por motor:

```bat
scripts\25-smoke-coqui.bat
scripts\26-smoke-piper.bat
scripts\27-smoke-ffmpeg.bat
scripts\28-smoke-motores-producto.bat
```

El test `RealEnginesSmokeScenarioTest` ejecuta solo los motores seleccionados en `docupodcast.realEnginesSmoke.required`.
