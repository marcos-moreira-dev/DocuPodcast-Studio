# Tanda 106B — Sidebar imagen/audio refinado

T106B corrige el comportamiento de imagen/audio del sidebar antes de T107:

- botón `Reproducir fragmento` además de `Reproducir desde aquí`;
- más estilos base para el combo de voz IA.
