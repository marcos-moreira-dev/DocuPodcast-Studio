# Tanda 10B implementada

Se agregó importación de muestras de voz como assets `VOICE_SAMPLE` portables.

Comandos visibles:

```text
Voz → Importar muestra para Mi voz…
Toolbar → Importar muestra
Workspace Voces → Importar muestra para Mi voz…
```

La muestra se copia a:

```text
voices/samples/
```

No se incluyen audios personales en el repositorio.
