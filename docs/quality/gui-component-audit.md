# GUI component audit and migration matrix

## Scope and rule

The product keeps JavaFX semantics for focus, keyboard and accessibility, but the application body
must be built through the shared visual catalog. A component is official only when its constructor
belongs to a catalog factory and it carries `StudioControlDescriptor` runtime metadata.

The only visual exceptions are response buttons generated by a dialog `ButtonBar` and the native
chrome of operating-system file/directory choosers. Fields, selectors, checkboxes, lists and actions
inside a dialog are not exceptions.

## Audited baseline and cutover

| Family | Direct constructions before cutover | Official owner after cutover |
|---|---:|---|
| Selection (checkbox, radio, combo, color) | 94 | `StudioFormControls` |
| Text, numbers and sliders | 66 | `StudioFormControls` |
| Lists, trees and tables | 27 | `StudioCollectionControls` |
| Navigation, tabs and menus | 11 | `StudioNavigationControls` |
| Progress | 9 | `StudioFeedbackControls` |
| Scroll and split viewports | 41 | `StudioViewportControls` |
| Application toggles | 2 | `StudioFormControls` |
| **Total** | **250** | **0 direct product constructions** |

Buttons remain owned by `ActionButtonFactory`; accordions and titled panes by `StudioAccordion`.
Product dialogs use `StudioDialogShell`, native responses use `NativeDialogResponse`, and operating-
system selection uses `NativeSourceChooser`.

## Visual contracts

- Forms expose `REGULAR`, `COMPACT` and `EDITOR` metadata variants.
- Sliders have an anchored track/thumb skin with hover, focus, disabled and both orientations.
- Progress supports normal, indeterminate, success, warning and error style states.
- Accordions retain a purple header, white title/arrow and white expanded content.
- Collection, navigation and viewport controls preserve native interaction but do not depend solely
  on Modena appearance.
- Product CSS may arrange controls or express domain state, but may not recreate their base skin.

## Automated evidence

- The bytecode audit rejects direct JavaFX constructors, including diamond-generic forms.
- The source audit produces `target/reports/gui-usage/gui-component-usage.md` on every test run.
- The runtime audit traverses logical content (not private skins) and rejects audited controls without
  `StudioControlDescriptor`.
- TestFX verifies keyboard focus, accessible naming, dialog exceptions, sliders, progress and the
  accordion color contract.
