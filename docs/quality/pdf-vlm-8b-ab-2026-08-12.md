# PDF VLM 4B Q8 vs 8B Q8 - P1 controlled gate

Date: 2026-08-12

## Decision

Qwen3-VL 8B Instruct Q8_0 does not pass the P1 gate. It improves the raw
geometric tightness compared with the defective canonical 4B result, but it
reduces semantic granularity and violates Block V1. The recommended next
investigation is a separate layout/segmentation stage followed by semantic
understanding. P2 and P3 were not run.

The official Ollama catalog does not publish a reliable Q6 tag for Qwen3-VL 8B
Instruct. The controlled candidate was therefore the official
`qwen3-vl:8b-instruct-q8_0`; no third-party GGUF or custom conversion was used.

## Controlled inputs

- Source: `D:/Proyectos/Demostracion_limite_notable.pdf`, page 1.
- Rasterization: 180 DPI, 1488 x 2104 in the production run.
- Same production prompt, Block V1 parser, validator, verifier, merger and
  recovery policy.
- `num_ctx=8192`, `temperature=0`, `seed=42`, `think=false`, batch 512.
- Flash Attention enabled, Q8_0 KV cache, history 0, Qwen concurrency 1.
- Primary output budget: 1800 tokens for both models.

## Semantic and grounding comparison

### 4B Q8

Primary output:

- 9 regions: TITLE 1, SUBHEADING 1, SIDEBAR 1, PARAGRAPH 3, IMAGE 1,
  CAPTION 1, MATH 1.
- Largest primary area ratio: 0.0616.
- Mean primary area ratio: 0.0361.
- Median primary area ratio: 0.0352.
- Primary segmentation was useful and text coverage was high.
- IMAGE preserved labels but omitted SPEECH.
- The verifier supplied good relational speech, but returned bbox
  `0,0,1000,1000`. The canonical page therefore contains one UNUSABLE image
  highlight.
- Canonical grounding classification: EXACT 8, COARSE_BUT_USEFUL 0,
  UNUSABLE 1.
- Canonical largest area ratio: 1.0.
- Block V1: valid in primary and verifier; canonical page accepted after
  verifier, without recovery.

### 8B Q8

Raw output before atomic rejection:

- 6 declared regions: PARAGRAPH 4, `BOXED_TEXT` 1 and IMAGE 1.
- Largest raw area ratio: 0.0645.
- Mean raw area ratio: 0.0473.
- Median raw area ratio: 0.0492.
- No full-page bbox was emitted.
- Raw grounding classification: EXACT 4, COARSE_BUT_USEFUL 1, UNUSABLE 1.
- It merged title and subtitle into one PARAGRAPH, and merged the closing
  paragraph with the independent displayed formula.
- It emitted the unauthorized type `BOXED_TEXT`.
- It closed IMAGE before SPEECH and then emitted another END.
- IMAGE SOURCE preserved visible labels, but SPEECH was only the caption; it
  did not describe the circle/sector/tangent relationships.
- MATH text preserved the inequality but lost its independent semantic region.
- Block V1: invalid. Java rejected the entire page and did not publish a
  PreparedPdfPage, run verifier or run recovery.

TABLE quality was not exercised on P1. P2 contains the table gate, but was not
run because 8B failed P1.

## Product recommendation

- Keep 4B Q8 as the default selectable profile for now.
- Keep 8B Q8 installed/configurable for research and future hardware; do not
  automatically fall back between quantizations or models.
- Do not promote 8B Q8 as the preferred PDF reader based on this gate.
- Evaluate a two-stage design next: layout/segmentation first, then semantic
  transcription/description. Do not try to repair this result by immediately
  adding more prompt phrases.

Evidence is preserved under `target/pdf-vlm-ab/4b-q8-p1` and
`target/pdf-vlm-ab/8b-q8-p1`.
