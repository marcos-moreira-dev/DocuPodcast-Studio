# Lecturas estratégicas de Domain Model Studio/UENS

## Tanda 1 — Bootstrap

DMS aporta `DomainModelStudioApp`, `ApplicationBootstrap`, `ApplicationRuntime`, factories de infraestructura/aplicación y composición explícita.

## Tanda 2 — Shell y tabs

DMS aporta shell multiproyecto, tabs reordenables, sesiones por tab, estado global, pantalla de inicio y ruteo de workspaces.

## Tanda 3 — Toolbar

DMS aporta toolbar global/contextual, contributors, actions, executor, políticas de capacidad y tests contra promesas falsas.

## Tanda 4 — SideDock

DMS aporta SideDock modular con carril vertical, un módulo activo, ayuda operativa, scroll controlado y mínimo visual de 8 filas.

## Tanda 5 — Workbenches

DMS separa workspaces estructurados y visuales. DocuPodcast debe usar estructurados para Documento/Guion/Audio/Voces y visual para Storyboard.

## Tanda 6 — Diccionario de datos

Referencia para documento estructurado, preview, formularios, Markdown/PDF y separación editor/preview.

## Tanda 7 — Levantamiento lógico

Referencia para guion/expediente estructurado: selección única, validación, trazas, ayuda, glosario y contrato Markdown.

## Tanda 8 — Canvas común

Referencia para Storyboard vivo: zoom, pan, fit, capas, selección, drag, export PNG y perfiles de interacción.

## Tanda 9 — Persistencia `.dms`

Referencia para proyecto JSON versionado, assets relativos, payload consistency y formato editable.

## Tanda 10 — Markdown/Recursos IA

Referencia para frontmatter, dispatcher, batch import, recursos IA exportables, índice y contratos importables.

## Tanda 11 — Guía integrada

Referencia para guía tipo CHM, búsqueda local, temas Markdown y ayuda operativa separada.

## Tanda 12 — CSS

Referencia para tema claro, tokens, toolbar, tabs, SideDock, workbench, manual y tests CSS.

## Tanda 13 — Exportación

Referencia para salida activa, formatos por capacidad, exportación por lote, README/MANIFEST y PNG por bounds reales.

## Tanda 14 — Tests

Referencia para guardarraíles de arquitectura, tests fuente, productización y documentación viva.

## Tanda 15 — Mapa final

DMS = base principal de scaffolding JavaFX.
