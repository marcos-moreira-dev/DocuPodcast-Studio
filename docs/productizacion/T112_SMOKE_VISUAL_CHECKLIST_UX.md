## Escenarios mínimos

- Abrir app.
- Abrir fuente documental.
- Verificar imágenes embebidas DOCX cuando existan.
- Escuchar sin proyecto previo y activar guardado guiado.
- Crear proyecto asistido.
- Seleccionar oración.
- Elegir voz/audio/imagen como capas.
- Mostrar/ocultar overlay de chunks.
- Recuperar overlay desde status bar.
- Mostrar/ocultar rail derecho.
- Cambiar tamaño de lectura.
- Exportar cuando readiness lo permita.
- Guardar, cerrar y reabrir.

## Criterios

- No cabina de avión.
- No botones falsos.
- No textos truncados.
- No placeholders técnicos.
- No Whisper/STT visible.
- No acciones duplicadas con lógica distinta.
- La hoja sirve para estudiar y trabajar.
- La playbar se siente flotante y moderna.
- El overlay de procesos largos se puede ocultar sin cancelar.
