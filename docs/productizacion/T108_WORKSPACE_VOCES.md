# T108 — Workspace Voces

## Objetivo

Implementar Voces como workspace secundario real.

## Función

Registrar, grabar, importar y probar voces de referencia para Coqui/XTTS.

## Contenido

```text
ver voces disponibles
agregar voz
subir muestra de voz
grabar muestra
mostrar frase larga para leer
iniciar/detener grabación
guardar voz con nombre
probar voz
eliminar voz
```

## Reglas

- No se mezcla con Whisper.
- No es configuración técnica de motor.
- No se usa para asignar audio del computador a una oración.
- La voz registrada aparece después en el combo del Sidebar.

## Criterio de aceptación

- Permite crear una voz de referencia sin consola.
- Guarda la voz para usarla en Documento.
