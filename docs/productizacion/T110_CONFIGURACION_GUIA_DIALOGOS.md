# T110 — Configuración, guía y diálogos

## Objetivo

Pulir las superficies secundarias.

## Configuración

Debe ser ventana secundaria, no workspace.

Secciones visibles:

```text
Coqui/XTTS
Piper
FFmpeg
almacenamiento
rendimiento
diagnóstico
```

No debe mostrar Whisper/STT.

## Guía de uso

- Una sola Guía de uso.
- No Markdown crudo.
- Sin duplicar Primeros pasos.
- Sin promesas futuras.

## Diálogos

```text
Exportar
Revisar integridad
Error de motor
Preparar proyecto
Confirmar creación de proyecto
```

## Criterio de aceptación

- No hay botones truncados.
- No hay botones falsos.
- No hay submenús redundantes.
