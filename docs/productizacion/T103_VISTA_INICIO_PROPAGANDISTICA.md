# T103 — Vista Inicio propagandística

## Objetivo

Convertir Inicio en portada funcional, clara y visualmente atractiva.

## Estética

- Aire Microsoft/Office moderno.
- Colores sólidos.
- Figuras geométricas simples: círculos, polígonos, bloques decorativos.
- Limpieza visual.
- Nada de dashboard técnico.

## Función

```text
Abrir fuente documental
Abrir proyecto
Crear proyecto
Guía de uso
```

La acción principal debe ser Abrir fuente documental.

## Mensaje de producto

```text
Abre un documento.
Escúchalo.
Ajusta por oración si hace falta.
Exporta audio o storyboard.
```

## Criterio de aceptación

- Inicio no parece configuración ni diagnóstico.
- No muestra jerga técnica.
- Permite empezar rápido.
