# Roadmap posterior a T81F

Base: T81F deja la toolbar principal como superficie con iconos, grupos y acciones frecuentes. El cerebro V1 sigue congelado.

## T81G — Retiro o degradación de vistas secundarias redundantes

Objetivo: revisar las vistas que todavía existen como workspaces principales o rutas visibles y decidir su tratamiento.

Criterios:

- Documento sigue siendo el workspace operativo principal.
- Narración interna, Audio Jobs, Voice Library y Storyboard no deben competir con Documento en navegación normal.
- Las capacidades del cerebro no se eliminan por defecto; se reubican en Herramientas avanzadas o Configuración cuando aplique.
- Si una vista ya no aporta operación directa, debe ocultarse o degradarse.

## T82 — Release Candidate

Objetivo: preparar empaquetado, smoke real, guía de instalación, validación de modelos externos y cierre de no regresión.
