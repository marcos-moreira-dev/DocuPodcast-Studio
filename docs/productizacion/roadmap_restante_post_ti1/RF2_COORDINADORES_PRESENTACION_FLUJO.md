# RF2 — Coordinadores de presentación por flujo

## Objetivo

Que cada flujo visible tenga un coordinador de presentación propio.

## Flujos

- Abrir/importar documento.
- Guardado guiado.
- Escuchar/generar.
- Asignar media.
- Gestionar voces.
- Crear demo.
- Exportar.
- Mostrar/ocultar procesos.
