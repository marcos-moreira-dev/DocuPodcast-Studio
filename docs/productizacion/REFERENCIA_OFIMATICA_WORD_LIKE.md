# Referencia ofimática Word-like para rediseño futuro

## Propósito

Esta referencia no ordena copiar Microsoft Word, WPS Office ni ningún editor de texto. Su propósito es registrar pistas de diseño que han sobrevivido durante años en suites ofimáticas y que pueden ayudar cuando DocuPodcast entre a la fase de rediseño visual aplicado.

La captura de referencia aportada por el usuario queda archivada en:

```text
docs/referencias/ui/wps-office-wordlike-reference-2026-05-30.png
```

## Observaciones útiles

La captura muestra una interfaz de documento con rasgos que pueden inspirar DocuPodcast:

- página blanca centrada sobre fondo neutro;
- barra superior con grupos de acciones por intención;
- pestañas de herramientas;
- estilos visibles como “Normal” y “Título 1”;
- controles de formato agrupados;
- área de documento amplia, estable y legible;
- desplazamiento vertical claro;
- estado inferior con página, palabras, modo y zoom.

## Traducción correcta para DocuPodcast

DocuPodcast no debe convertirse en procesador de texto completo. La traducción correcta es:

| Patrón ofimático | Adaptación DocuPodcast |
|---|---|
| Página centrada | Documento narrado como página cómoda de lectura. |
| Ribbon / grupos | Toolbar contextual por intención: Abrir, Escuchar, Reproducir, Capas, Exportar. |
| Estilos Word | Información de estructura en Propiedades/Diagnóstico, no ruido principal. |
| Zoom | Controles de lectura: tamaño de texto, densidad, seguimiento activo. |
| Barra de estado | Estado humano: listo, generando, reproduciendo, esperando buffer, guardado. |
| Paneles laterales | SideDock/rail plegable para apoyo, no pared de opciones. |

## Límites

No se debe copiar:

- edición de texto enriquecido completa;
- todas las acciones de formato de Word;
- ribbon sobrecargado;
- sensación de suite ofimática generalista;
- promesa de modificar documentos fuente.

DocuPodcast debe seguir siendo:

```text
lector narrado de documentos + capas multimedia + motor local de audio/video detrás
```


## Regla resumida

- inspiración de lectura sí;
- edición ofimática completa no.

## Criterio para rediseño visual futuro

Cuando se rediseñe la cara de la app, la pregunta no debe ser “¿cómo hacemos un Word?” sino:

```text
¿Qué patrones de lectura y orientación de Word/WPS ayudan a que un usuario entienda, escuche y produzca un documento narrado sin ver la cabina técnica?
```
