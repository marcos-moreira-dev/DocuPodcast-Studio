# UX-RIBBON3 + DOC-RAIL6 — Ribbon y panel visual limpios

## Objetivo

Reducir ruido visual en la experiencia principal y eliminar controles redundantes del panel visual derecho.

## Cambios

- El Ribbon ya no muestra un botón transversal para abrir/cerrar el panel visual derecho.
- El panel visual queda controlado desde el Documento mediante su propio botón compacto.
- El botón del panel visual es solo icono; se elimina el texto/glyph duplicado `<` / `>`.
- El rail derecho del Documento deja de mostrar la sección genérica `Imágenes`.
- El rail queda centrado en tarjetas visuales ligadas a fragmentos.

## Criterio de producto

Una acción visible debe tener dueño claro. El panel visual pertenece al workspace Documento, no a todos los workspaces desde el Ribbon.
