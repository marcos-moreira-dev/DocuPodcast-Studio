# Roadmap post T69B — Frente honesto antes de nuevas capacidades

## Estado

T69 hizo editable la configuración y corrigió el frente para no prometer PDF sin importador. T69B corrige tests fuente desalineados por ese cambio.

## Decisión

Antes de seguir con nuevas capacidades de storyboard/video, el frontend debe discutirse y auditarse como producto:

1. El usuario normal debe vivir en Documento: abrir, leer, escuchar, pausar, reproducir desde selección y refrescar contenido.
2. Guion/narración avanzada, jobs, manifest, motores, rutas y diagnósticos deben quedar como capas avanzadas.
3. Configuración debe ser operativa y editable, pero no debe invadir la lectura.
4. El lenguaje visible debe hablar de Documento narrable, fuente solo lectura, capas y exportación, no de tuberías internas.

## Siguiente paso recomendado

T70 debería enfocarse en storyboard/video operativo solo si no rompe la simplicidad del Documento. Si el frente sigue pareciendo cabina técnica, conviene intercalar una auditoría UI específica antes de video.
