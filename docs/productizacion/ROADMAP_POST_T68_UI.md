# Roadmap post T68 — UI aplicada, storyboard/video, smoke y RC

## Base actual

T68 deja una primera versión de Documento/Inicio menos técnica y más alineada con lector narrado. La UI todavía no está cerrada, pero ya no debe avanzar mostrando métricas técnicas en el flujo principal.

## Tandas pendientes

| Tanda | Foco | Objetivo |
|---:|---|---|
| T69 | Storyboard/video operativo | Hacer que una imagen asociada dure lo que dura el texto hablado y que el paquete de video sea honesto. |
| T70 | Smoke integral | Ejecutar matriz manual con documentos simples, largos, técnicos, diálogos, errores y recuperación. |
| T71 | Packaging/RC | App-image/MSI, hashes, manifiestos, licencias, guías y limitaciones conocidas. |

## Regla para T69+

No agregar cabina técnica al Documento. Si una capacidad requiere manifest, jobs, FFmpeg, STT o diagnóstico, debe ir a vista avanzada o configuración.
