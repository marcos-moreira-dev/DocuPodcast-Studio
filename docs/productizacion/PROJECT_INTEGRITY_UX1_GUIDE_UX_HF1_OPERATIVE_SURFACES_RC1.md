# PROJECT-INTEGRITY-UX1 + GUIDE-UX-HF1 + UX-OPERATIVE-SURFACES-RC1

## Objetivo

Cerrar tres puntos de productización sin agregar relleno visual:

1. Avisar al usuario cuando un proyecto se abre con advertencias o requiere reparación.
2. Convertir la guía integrada en ayuda operativa, orientada a tareas reales.
3. Dejar guardarraíl para que las superficies visibles tengan propósito operativo.

## Decisión de producto

Todo elemento visible debe justificar una acción, decisión, estado, advertencia o siguiente paso. No se agregan tarjetas, métricas ni textos para aparentar dashboard.

## Integridad

Al abrir un proyecto, la app inspecciona integridad. Si hay advertencias o errores, muestra un diálogo con resumen y detalle técnico. La acción manual **Integridad del proyecto** también muestra diálogo: éxito si no hay hallazgos, advertencia/error si hay problemas.

## Guía

La guía queda centrada en:

- abrir y escuchar un Word;
- trabajar desde Documento;
- registrar voces y tonos;
- asignar imágenes;
- generar audio;
- exportar audio/video;
- resolver problemas comunes.

Se retira lenguaje rebuscado o heredado que no conectaba con una acción concreta.

## Guardarraíles

Tests fuente nuevos protegen:

- message box de integridad al abrir o inspeccionar proyecto;
- guía orientada a tareas;
- ausencia de lenguaje de dashboard decorativo en la guía;
- principio de superficies operativas.
