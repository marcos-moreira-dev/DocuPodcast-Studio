# T108 — Workspace Voces UX final mínimo

T108 aterriza la vista Voces como biblioteca de voces. No es una superficie para operar todo el audio del producto ni un panel de diagnóstico técnico.

## Contrato UX

- Lista de voces: muestra voces disponibles con nombre humano y estado de muestra.
- Detalle: explica tipo, motor, preset, capacidad real y uso recomendado.
- Muestra: permite importar o grabar `Mi voz` con frase de referencia.
- Documento: sigue siendo el lugar principal para asignar voz a una oración o fragmento.
- Configuración: sigue siendo el lugar para preparar Piper, Coqui/XTTS, FFmpeg y rutas.

## Honestidad de producto

`Mi voz` significa muestra propia/autorizada registrada en el proyecto. No significa clonación automática. Una voz puede ser asignable aunque el motor actual no pueda sintetizarla todavía.
