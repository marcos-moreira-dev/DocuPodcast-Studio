# Roadmap posterior a T81E

## Estado después de T81E

El workspace Documento ya tiene:

- menú principal reorganizado;
- pantalla de inicio sin acceso directo a Configuración;
- Documento central limpio de metadatos técnicos;
- barra flotante global de lectura;
- inspector izquierdo contextual;
- rail derecho visual de miniaturas/medios.



El cerebro detrás se mantiene, pero la UI normal debe girar alrededor de Documento.
