# ICON-INDEX-HF1 + RIBBON-LABELS-HF1

El icono del módulo Índice fue reemplazado por una imagen tipo árbol de carpeta: raíz, ramas y hojas. El objetivo es comunicar estructura documental, no diagrama técnico.

El botón de reproducción contextual del Ribbon usa `Reproducir desde aquí` y el componente transversal `RibbonButton` tiene ancho suficiente para evitar truncamientos innecesarios.
