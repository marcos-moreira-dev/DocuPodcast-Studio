# Nombres de assets teatrales

La relación semántica vive en el manifiesto; el filename solo mejora legibilidad.

- Personaje: `assets/personajes/<CHARACTER_ID>/<vista>.png`
- Objeto: `assets/objetos/<OBJECT_ID>/<vista>.png`
- Fondo/mapa: `assets/fondos/<id>.png`, `assets/mapas/<SCENE_ID>.png`
- Frame: `assets/frames/<INTERVENTION_ID>.png`
- Intermedio: `assets/frames_intermedios/<FROM>__<TO>.png`
- Audio humano: `assets/audio/<INTERVENTION_ID>.wav`
- Muestra de voz: `assets/voces/<VOICE_ID>.wav`

Los nombres recomendados no reemplazan `logicalId`, metadata, hash ni tamaño. No declarar un asset opcional ausente.
