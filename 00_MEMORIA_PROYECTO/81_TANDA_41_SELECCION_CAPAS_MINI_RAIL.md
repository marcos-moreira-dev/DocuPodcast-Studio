# Memoria — Tanda 41

Se incorpora la idea de selección transversal de capas sin modificar el Word original. Se agrega dominio de asignaciones narrativas (`NarrativeLayerKind`, `NarrativeLayerAssignment`, `NarrativeLayerAssignmentPolicy`) y se introduce un rail lateral plegable en Documento para preparar voz, audio, emoción, imagen/storyboard y ambiente.

El mini storyboard se define como sidebar/rail plegable y retraíble, no como panel pesado fijo. La tanda no persiste aún asignaciones ni implementa selección exacta por oración; deja la base arquitectónica y UI para hacerlo con menor acoplamiento.
