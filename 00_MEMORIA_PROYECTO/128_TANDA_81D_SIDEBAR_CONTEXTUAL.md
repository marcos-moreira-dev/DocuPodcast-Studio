# Memoria — Tanda 81D

T81D traslada las acciones frecuentes por oración al sidebar izquierdo contextual. El usuario hace clic en una oración y encuentra tres módulos: Detalles, Audio / Narración e Imagen. Esta tanda concreta la decisión de UX tomada durante el rediseño: el menú y toolbar quedan para acciones globales, mientras que las operaciones repetitivas sobre fragmentos viven en el inspector.

Decisiones congeladas:

- Usar `Voz IA`, no “guía”.
- Usar `Audio del computador` para archivos locales.
- Exponer `Elegir audio…` y `Extraer audio de video…` como acciones directas.
- Emoción/estilo solo con voz generada por IA.
- El rail derecho queda visual/navegacional; no debe volver a ser una botonera de capas.
- Todo lo nuevo debe usar componentes GUI transversales.
