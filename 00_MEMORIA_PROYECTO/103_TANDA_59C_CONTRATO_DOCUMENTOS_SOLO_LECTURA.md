# Memoria — Tanda 59C

Decisión registrada: en la versión actual, todo documento fuente se abre en modo solo lectura. Esto cubre Word/DOCX, PDF, Markdown/MD y TXT.

Razón: DocuPodcast debe operar como lector narrado y fábrica de artefactos del proyecto, no como editor de documentos fuente. Cualquier voz, emoción, imagen, audio, storyboard o nota se guarda como capa/metadato del proyecto, no dentro del archivo original.

También se registra una referencia ofimática Word-like aportada por el usuario para rediseño visual futuro. La inspiración permitida es legibilidad, página centrada, grupos de acciones, estado y zoom; no edición ofimática completa.
