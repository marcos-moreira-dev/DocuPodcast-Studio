# Memoria — Tanda 38

Se fija una regla arquitectónica visual: la UI debe crecer con componentes GUI transversales y CSS modular. No se debe repetir JavaFX suelto en cada workspace cuando exista un patrón común.

Esta tanda prepara la base para implementar después reproducción por chunks, botón inteligente, selección de texto, mini rail multimedia y storyboard simple sin multiplicar layouts inconsistentes.
