# Memoria — Tanda 81E

T81E consolida la decisión visual tomada por el usuario: el centro es Documento; el sidebar izquierdo opera el fragmento; el sidebar derecho muestra miniaturas y medios con navegación al texto relacionado.

Se agregó `MediaThumbnailCard` como componente transversal para evitar tarjetas ad-hoc dentro de `DocumentMediaRailView`.

También se compactó la barra flotante: la explicación larga de la acción principal queda como tooltip para que los botones de lectura no se compriman.
