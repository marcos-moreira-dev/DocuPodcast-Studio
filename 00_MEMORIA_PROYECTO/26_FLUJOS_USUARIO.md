# Flujos de usuario

## Flujo académico

```text
Abrir Word con notas
Revisar estructura
Ajustar perfil de lectura
Crear guion
Generar audio
Escuchar mientras se estudia
Exportar podcast
```

## Flujo teatral

```text
Importar guion
Crear personajes
Asignar voces
Asignar estilos a segmentos
Generar audio por escenas
Asociar imágenes
Reproducir storyboard vivo
```

## Flujo storyboard

```text
Crear guion
Importar imágenes
Asociar imagen a segmento
Previsualizar escenas
Reproducir audio con imagen
Exportar paquete storyboard
```

## Flujo recuperación

```text
Generar audio
Cancelar o fallar
Reabrir proyecto
Ver segmentos completados/fallidos
Reintentar fallidos
Exportar final
```
